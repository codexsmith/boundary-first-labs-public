# Start Here

**Trace what follows. Design for repair.**

Boundary First Labs studies what happens when models, software, institutions, or scientific representations omit distinctions that matter to the resulting action or consequence.

For a first visit:

1. Read [the Lab's purpose](../README.md).
2. Explore [Boundary First as a method](../method/README.md).
3. Read [the theory and formalization program](../theory/README.md) without assuming its hypotheses are established.
4. Browse [research areas](../research/README.md) and [released projects](../projects/README.md).
5. Look for explicit evidence, corrections, version, and licensing **before** reusing any particular work.

Readers should not need to understand the private research corpus, its folder codes, or its agent machinery to navigate this repository. Public materials should explain familiar concepts first and introduce specialized formal vocabulary only when useful.

For a concrete demonstration, start with [The Model Forgot the Boundary](01-the-model-forgot-the-boundary.md), then follow it to the n-ball mathematical package.

**Current release stage:** the navigation framework is present; substantive project releases remain separately governed.
