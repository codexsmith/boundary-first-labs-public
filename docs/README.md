## Public-state rule

A reader-friendly index or generated view is a **projection**. A released project bundle owns the **specific public release bytes**. The private Lab's canonical owners continue to govern **underlying working research**, evidence, and promotion status.

Do not infer missing or existing projects from empty folder names. Material not publicly released is outside this repository.

## Folder rule

Use plain-language, kebab-case paths, not private numeric corpus identifiers. Keep a project physically together. Use links and manifests for cross-cutting views. Create extra folders only when actual cleared objects require them.
