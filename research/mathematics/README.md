# Mathematics and Formal Systems

Public route for mathematical constructions, logic, proof-oriented investigations, formalisms, and explicit comparisons with conventional work.

Every release should identify established theorems/formulas, prior art, the exact BFL construction or relation, its proof obligations, what remains conjectural, and any negative or reduction result.

**The mathematical object or truth is not owned merely because a new explanation or executable representation is published.** Rights in original text, figures, and code are addressed separately in [Licensing](../../LICENSING.md).

## First public example

- [The n-Ball: Construction, Recursion, and What a Summary Forgets](../../projects/n-ball-boundary-recursion/README.md) — classical geometry, explicit typed construction, mathematical counterexample and bounded reproducibility. **Educational release, not a new theorem.**
