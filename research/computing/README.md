# Computing and Engineered Systems

Public route for software architecture, formal programming, information systems, agentic computation, research instruments, and engineering demonstrations.

A software release should provide a versioned project owner, dependency/license inventory, source, tests, known limitations, and an explicit software license **if** rights and publication are approved. A successful test does not establish all intended real-world consequences.

See [software releases](../../software/README.md), [project packages](../../projects/README.md), and [licensing](../../LICENSING.md).
