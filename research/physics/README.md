# Physics and Natural Systems

Public route for domain-bounded physical models, geometry-to-physics comparisons, experiments, and observational constraints.

For each project, separate **mathematical correctness**, **physical interpretation**, and **empirical adequacy**. Supply units, assumptions, benchmark/reference models, measurement or simulation conditions, uncertainty, and failed tests where relevant.

Formal analogy does not establish a new physical law. This area links to cleared [project releases](../../projects/README.md); it does not own duplicate experimental records.
