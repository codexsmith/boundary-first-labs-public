# Software and Executable Demonstrations

This is the reader-facing index of **approved public code releases**. The actual code, tests, dependencies, version, and license are kept with the owning [project package](../projects/README.md).

Before publishing any code, verify its legal owner, third-party dependencies, export and privacy constraints, test evidence, and the explicit scoped software license. **Apache-2.0 is the prospective default for approved BFL open-source packages**, with alternatives only by deliberate review; this statement alone grants no license.

A research notebook, prototype, or reproducible simulation must describe its scope and limitations; execution is not formal proof or external validation.

No executable release ships in this skeleton.
