# Publications

This is a **catalog and reading surface** for public essays, technical notes, papers, demonstrations, and reports. It does not store a second active copy of research already owned by a project package.

Before listing a publication, verify its release manifest, audience, claim ceiling, sources, corrections, version, and per-artifact licensing. A public document can be a clearly labeled working hypothesis or negative result; publication does not mean peer review, proof, or product readiness.

Publication objects should link to the immutable public release or tagged project version under [projects](../projects/README.md), and not to inaccessible private source paths.
