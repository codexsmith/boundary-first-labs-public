# Public Repository Traversal Contract

This file is a public navigation and contribution guide, **not** the private Lab's execution-control plane.

1. Start at the repository `README.md`, then `docs/README.md` for the map.
2. Route by intended reader task: `about/`, `method/`, `theory/`, `research/`, `projects/`, `publications/`, or `software/`.
3. For a released artifact, read its project-local README and release manifest before interpreting claims or permissions.
4. Resolve one public project package as the owner of a released artifact. Other categories are indexes or presentations, not parallel canonical copies.
5. Preserve inherited sources, BFL-specific additions, evidence, limitations, negative results, version, and correction history.
6. Respect `LICENSING.md` and `PUBLICATION_POLICY.md`. Public visibility is not a license. Never treat a draft or template as a licensed release.
7. Do not import private research snapshots, raw chat exports, sensitive data, internal registries, execution machinery, or unpublished third-party assets into this repository.
8. Propose corrections with explicit sources and reproducible witnesses. An automated rewrite does not authorize scientific promotion or public release.

For repository-shape changes, read `docs/decisions/`. Record a successor decision rather than erasing the rationale for the prior structure.

**Public routes guide discovery; project releases carry content; release metadata carries status and rights.**
