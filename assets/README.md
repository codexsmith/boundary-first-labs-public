# Public Assets

This directory is reserved for public-cleared original diagrams, media, and other assets that genuinely need a shared public home.

Prefer project-local figures and data when they belong to one work. Do not copy private research screenshots, third-party photographs, fonts, or unpublished media merely because they are helpful for a presentation.

Each later asset needs an identifiable creator/rightsholder, source, approved permission or license, attribution obligations, and any exclusions for logos and trademarks.

See [Licensing](../LICENSING.md). This README is a route, not an approval to use any particular asset.
